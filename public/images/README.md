logo.png

gallery-4.jpg
gallery-5.jpg
gallery-6.jpg

gallery-8.jpg
barber-1.jpg
barber-2.jpg
barber-3.jpg

You can drag and drop files into this folder in GitHub. Keep the exact filename for the slot you want to replace. The GitHub Pages build will automatically redeploy after the commit.

Recommended sizes:
logo.png: transparent PNG, square or close to square
hero.jpg: landscape, ideally 1600 x 1000 or larger
gallery images: square or portrait, ideally 1200 x 1200 or larger
barber images: square, ideally 1200 x 1200 or larger
