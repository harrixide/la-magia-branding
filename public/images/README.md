# Image slots

Upload replacement images into this folder using these exact filenames.

## Full webpage section backgrounds

Use these exact filenames to replace the background image for each full section of the website:

1. `hero.jpg` controls the first Home or Hero section.
2. `section-1.jpg` controls the Our Story section.
3. `section-2.jpg` controls the Services section.
4. `section-3.jpg` controls the Our Work section.
5. `section-4.jpg` controls the Booking section.
6. `section-5.jpg` controls the Visit section.

To change a section background, drag and drop the new image into `public/images` in GitHub using the exact matching filename, replace the existing file if prompted, and commit the change. The GitHub Pages build will redeploy automatically.

The website CSS already points each section to these filenames, so you should not need to edit code each time you replace an image.

The section backgrounds use a transparent dark overlay so text remains readable while the uploaded photo stays visible.

## Recommended sizes

`logo.png`: transparent PNG, square or close to square

`hero.jpg`: landscape, ideally 1600 x 1000 or larger

`section-1.jpg` through `section-5.jpg`: landscape, ideally 1600 x 1000 or larger

Gallery images: square or portrait, ideally 1200 x 1200 or larger

Barber images: square, ideally 1200 x 1200 or larger
